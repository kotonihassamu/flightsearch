## Phase 0 — 技術検証

> 完了条件: いずれかの方式で3日連続、価格・時刻・航空会社名が取得できる

> **2026-07 実機検証で判明した重要事項**
>
> - fast-flights は **3.0.2** が入る（要件執筆時の2系とは **APIが全面変更**）。
>   `FlightData` は廃止 → `FlightQuery` + `create_filter` + `parse` になった。
> - fast-flights 3.x の内部HTTPクライアント **primp が、環境によってはDNS
>   "Query Refused" で失敗する**（独自DNSリゾルバのため）。検証環境で発生。
> - 対策として本体は **取得を requests、解析を fast-flights の parser** に分離
>   （primp完全回避）。`FastFlightsFetcher` はこの方式で実装済み。
> - この方式で HND→HIJ の実便・実価格（ANA 20,590 / JAL 22,790）を取得成功。
